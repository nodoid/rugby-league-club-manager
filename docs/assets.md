# Assets

All raster art in the game is original and generated by one script, so the palette and proportions
stay consistent and nothing depends on third-party artwork.

```bash
pip install pillow
python3 tools/generate_assets.py
```

The script writes:

| Destination | Contents |
| --- | --- |
| `src/RugbyLeague.Game/Content/Textures/` | In-game textures used by the shared game project. |
| `src/RugbyLeague.Android/Resources/mipmap-*/` | Launcher icons at every density, round icons, adaptive foregrounds. |
| `src/RugbyLeague.Android/Resources/mipmap-anydpi-v26/` | Adaptive icon XML (foreground + monochrome). |
| `src/RugbyLeague.Android/Resources/Drawable/` | `splash_logo.png`, legacy icon. |
| `src/RugbyLeague.Android/Resources/Values/` | Splash colours and styles, including the Android 12+ splash screen. |
| `src/RugbyLeague.iOS/Assets.xcassets/AppIcon.appiconset/` | Single 1024×1024 app icon. |
| `src/RugbyLeague.iOS/Assets.xcassets/LaunchImage.imageset/` | Launch images. |
| `docs/images/` | Preview art used in this documentation. |

## In-game textures

| File | Size | Use |
| --- | --- | --- |
| `background.png` | 1920×1080 | Full-screen page background behind menus and the hub. |
| `splash.png` | 1920×1080 | Splash and menu artwork. |
| `logo.png` | 1024×1024, transparent | Header mark; drawn with the team's colours. |
| `panel.png` | 96×96 nine-slice | Cards, panels, tables and scroll regions. |
| `button.png` | 96×96 nine-slice | Buttons (gold primary, ghost and normal styles tint it). |
| `pitch.png` | 2048×1392 | Top-down pitch markings, drawn with the correct 100×68 aspect. |
| `grass.png` | 512×512, tileable | 3D ground plane texture. |
| `ball.png` | 128×128 | Ball marker in the top-down view. |
| `marker.png` | 64×64 | Player markers. |
| `shield.png` | 256×256 | Club crest shape behind the short code. |
| `trophy.png` | 256×256 | Competition and title screens. |

Textures are loaded once in `RugbyGame.LoadContent` via the MonoGame content pipeline
(`Content.mgcb`), so they are compressed/packed by the same build on every platform.

## Icons and splash screens

- **Android**: legacy launcher icons are generated at mdpi 48, hdpi 72, xhdpi 96, xxhdpi 144 and
  xxxhdpi 192 px, plus round variants and a 108 dp adaptive foreground inside the safe zone. The
  Android 12+ splash uses `windowSplashScreenBackground` and `windowSplashScreenAnimatedIcon` with
  the dark green brand colour and the logo, and a matching legacy `windowBackground` for older API
  levels.
- **iOS**: the asset catalog contains a 1024×1024 opaque app icon (no transparency, as the App Store
  requires) and launch images for the launch storyboard.
- Both platforms also show an in-game splash screen (`SplashScreen`) that draws `splash.png`, so the
  transition from the OS splash to the menu is seamless.

## Fonts

The UI uses **Open Sans** (regular and bold), licensed under the SIL Open Font License. The licence
text is bundled at `src/RugbyLeague.Game/Content/Fonts/OFL.txt` and is included in the repository as
the licence requires.

Five SpriteFonts cover the type scale. SpriteFont `<Size>` is in points and the content pipeline
rasterises at 4/3× pixels, so the values are chosen to give round pixel sizes on a 720-unit canvas:

| Font | `<Size>` | Rendered | Use |
| --- | --- | --- | --- |
| `FontSmall` | 12.75 | 17 px | Labels, table rows, footnotes |
| `FontBody` | 16.5 | 22 px | Body copy, buttons |
| `FontSubhead` | 20.25 | 27 px | Card headings |
| `FontHeading` | 27 | 36 px | Screen titles |
| `FontTitle` | 45 | 60 px | Hero titles |

The character regions include Latin-1 punctuation and the accented characters used by club and
player names, so nothing renders as a missing glyph. If you edit a `.spritefont`, rebuild the content
project (a normal `dotnet build` of any head does this).

## Editing the art

`tools/generate_assets.py` is organised as small functions (`logo_image`, `background_image`,
`splash_image`, `pitch_texture`, `ui_panel`, `ui_button`, `ball_texture`, `marker_texture`,
`shield_texture`, `trophy`, `android_icons`, `ios_assets`). The palette is defined at the top of the
file (`NAVY`, `DEEP_GREEN`, `GRASS`, `RED`, `GOLD`, `WHITE`, `CREAM`). Change the palette or a
function and rerun the script; nothing is hand-edited, so the outputs stay reproducible.

Keep these constraints when changing sizes:

- `pitch.png` must stay 100:68 so the top-down view is not distorted.
- `panel.png` and `button.png` are nine-sliced, so their corners must remain undistorted.
- The iOS app icon must be opaque and exactly 1024×1024.
- Android adaptive foregrounds need the artwork inside the central 66% safe zone.
